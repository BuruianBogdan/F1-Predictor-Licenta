# Circuit atlas and editorial UI assets

## Real driver photographs

`scripts/enrich_driver_portraits.py` discovers the official current-season directory at https://www.formula1.com/en/drivers, matches actual driver identities, and stores original CDN asset URLs as `formula1_hd` media. The thumbnail transformations are removed; existing tiny OpenF1 images are not artificially enlarged. Verification found 22 matched current drivers, with native assets up to 1336 × 3840 pixels. Images remain remote, with a local vector silhouette if unavailable. Official photos and trademarks belong to their respective owners and are not generated by AI. Subsequent OpenF1 refreshes preserve the higher-resolution portrait.

## Circuit geometry

`backend-python/resources/circuit_layouts.json` contains 33 circuit outlines matched by real circuit location to the [f1-circuits GeoJSON dataset](https://github.com/bacinger/f1-circuits). The included `CIRCUIT_LICENSE.txt` preserves its MIT license and attribution. `scripts/build_circuit_assets.py` rebuilds the assets from source. Rendering uses SVG paths in a 500 × 300 viewBox and scales sharply at every screen density. Reference geometry may differ from historical configurations; the UI discloses this. The marked point is the first reference geometry coordinate, not an independently verified timing line.

The winner panel positions the reference circuit between winner copy and photograph on desktop. Upcoming race detail pages have a large track panel. All calendar cards show their own circuit. Calendar ordering: future scheduled races ascending by date/round; completed races descending by date/round; unverified past rounds and cancelled/postponed events are separate.

## UI

The design retains the existing dark/light themes and adds a circuit calendar, three-column winner panel, current-driver portrait grid, editorial news grid, Romanian/English navigation and a dashboard news preview. On mobile, navigation uses two visible rows and cards reflow without horizontal page overflow. Keyboard focus, semantic links and reduced-motion preferences remain supported. News summaries use the configured language rather than being re-generated when the UI language selector changes.


Race Control transitions use the user-supplied `Fundal abstract de curse cinematice.png`, copied unchanged to `static/images/race-control-background.png`. Driver photos reuse the existing native-resolution Formula 1 assets. The viewer map uses measured OpenF1 lap coordinates so car dots and outline share the same coordinate system.
