Time is the boundary.

For race N, features come only from earlier events. Finishing position, points and status from race N are labels used after the race, never prediction inputs.

Pre-weekend mode excludes qualifying and grid. After-qualifying mode uses timestamped qualifying only; final race-grid values are not imported as pre-race observations.

Prediction ≠ certainty.

A driver with a 30% estimate still loses in most possible outcomes. The model reports uncertainty, and a separate baseline makes improvements measurable.

The LLM explains existing numbers. It does not calculate probabilities. Market adjustment is optional and never places bets.

Measured, not promised.

What this model cannot know.

Weather, race incidents, strategy and development can change the outcome. Current features do not model telemetry or tyre strategy. Historical rosters are reconstructed, and future line-ups are projected from the latest known field.
